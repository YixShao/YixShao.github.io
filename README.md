# Yixuan Shao (邵一轩) — Academic Website

Source for the personal academic website of **Yixuan Shao (Yi-Xuan Shao, 邵一轩)**, an astronomy PhD student at Nanjing University.

Visit the website: **[yixshao.github.io](https://yixshao.github.io/)**

Research interests include pulsars, neutron stars, fast radio bursts, supernova remnants, and multi-wavelength astronomy.

The site is built with Hugo Blox and deployed automatically to GitHub Pages from the `main` branch. Its XML sitemap is available at [yixshao.github.io/sitemap.xml](https://yixshao.github.io/sitemap.xml).
